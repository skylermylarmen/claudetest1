FIAMMA

Before we begin Nothing here is final. This isn't even an official moodboard. It's a presentation of references, notes and directions to react to, not a finished brand identity, and every visual on this page is a concept.

The idea

Fire, taking different forms.

Fiamma is Italian for flame. The studio becomes a living light that changes with the time of day, the class and the heat. It feels crafted and high-end, with a little feminine spark, and it's made for every body.

01

Walls that breathe

Projection walls glow, shift color and pulse with each class. Every class gets its own set.

02

A kit of light

One toolkit of effects (glow, grain, heat, countdowns) shared by the walls, socials and website.

03

Italian craft

Carved serifs, a crest and a hand-painted mark, with a cheeky voice: "You look hot."

I

The Space

A walk-through in order: the hallway, the main walls and their moods, then the details. Each stop includes buildout notes.

Ref 01
Space · Entry & hallway

Led in by light

The hallway stays dark. The only light comes from an LED strip on the ceiling that runs down the hall and pulls you into the main room.

  • Buildout: recessed LED channel down the center of the ceiling
  • The strip takes the color of whatever class is running inside
EntryLED
Ref 02
Space · Main walls

The primary example

This is what the projection walls should feel like. It's the main state in the Kit, with endless potential.

  • Breathes with the class, inhale and exhale
  • Color-changing, with a set for every class
  • Buildout: perforated or mesh panels over LED/projection, with slim dark seams
Main wallsBreathe mode

Mode · Sunrise

Low light, early mornings

Easy on the eyes, with a super chill, healing feel. Great service plus the heat makes an amazing way to wake up.

  • A single warm, glowing stone shape
  • Amber haze, with everything else dark
Sunrise mode

Bright, soft, open

For a midday class or welcome session, this shows how far the screens can stretch in mood.

Mode · Burlesque intro

A showstopper

Every class has its own projection set. For burlesque, the intro is silhouettes moving behind frosted red glass.

Space · Feature circle (optional)

The accent spot

An accent beside the main walls that's more class-specific. It shows the class name and emblem on a cycle, in step with the walls.

II

The Kit

The effects behind the room. They're used across the walls, the socials and the website.

Ref 09
Kit · Heat-up

Heat you can see

This is the main element of the Kit. Heat is the core idea, so it plays while the room warms up.

  • Light tubes behind a pane of ribbed glass, glowing from the bottom up
  • The color changes depending on the class
KitHeat-up mode
Ref 10
Kit · The Floor

Countdowns & the text sphere

For the fitness area, which we're calling The Floor. These project on the walls for countdowns and finisher sequences.

  • Giant timers that roll as the set winds down
  • The 3D sphere of text is a must-have. It can be built from class words, or even members' names
  • Both could move in rhythm with the class during the intense sections

Type & Identity

Identity · Italian craft

Carved serifs & a crest

The name is Italian, so the type can be too. Beautiful carved serifs and an engraved crest give an elevated, versatile base.

  • High-end and crafted, with a real cultural touch point
  • Not the be-all and end-all. It's a direction to fuse with the atmosphere
